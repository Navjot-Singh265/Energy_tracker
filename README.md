# Energy Tracker

A web-based application for tracking and monitoring energy consumption. This project provides an intuitive interface to log, visualize, and analyze energy usage patterns over time.

## Overview

Energy Tracker helps users monitor their energy consumption habits with ease. Whether you're looking to reduce your carbon footprint, lower utility bills, or simply understand your energy usage better, this application provides the tools you need.

## Features

- 📊 **Track Energy Usage**: Log energy consumption data with timestamps and device information
- 📈 **Visualize Data**: Interactive charts and graphs to understand consumption patterns
- 🔍 **Detailed Analytics**: Analyze trends and identify peak usage periods
- 💾 **Data Storage**: Persistent storage of all energy consumption records
- 🎨 **User-Friendly Interface**: Clean and intuitive web-based UI

## Technologies Used

- **Frontend**: HTML, CSS (67% of codebase)
- **Backend**: Python (32% of codebase)
- **Architecture**: Web-based application

## Installation

### Prerequisites
- Python 3.x
- A modern web browser
- pip (Python package manager)

### Setup

1. Clone the repository:
```bash
git clone https://github.com/Navjot-Singh265/Energy_tracker.git
cd Energy_tracker
```

2. Install Python dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python app.py
```

4. Open your browser and navigate to:
```
http://localhost:5000
```

## Usage

1. **Log Energy Usage**: Enter your energy consumption data in the form
2. **View Dashboard**: See your energy consumption statistics and trends
3. **Analyze Patterns**: Use charts to identify when you use the most energy
4. **Export Data**: Download your data for further analysis
